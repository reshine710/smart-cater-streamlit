# 🔔 AI 推薦通知功能說明

## 功能概述

AI 推薦通知功能會在側邊欄頂部顯示待審核和已通過的 AI 推薦，提供即時的訊息提醒，讓使用者能夠快速了解和處理 AI 團隊的推薦。

## 主要特性

### 1. 通知顯示位置
- 位於側邊欄最頂部，在使用者資訊區域之前
- 醒目的紅色徽章顯示未讀訊息數量
- 展開式設計，不占用過多空間

### 2. 通知內容

#### 包含的推薦類型：
- 🟡 **待審核推薦 (PENDING)**：需要管理員審核的新推薦
- ✅ **已通過推薦 (APPROVED)**：已審核通過但尚未實施的推薦

#### 推薦分類：
- 🍽️ **菜單預測 (DYNAMIC_MENU)**：AI 推薦的動態菜單配置
- 📦 **庫存預測 (RESTOCK)**：AI 推薦的補貨建議

### 3. 顯示資訊

每個推薦通知包含：
- **推薦ID**：唯一識別碼（如 AI-REC-20251108-001）
- **機台代碼**：目標機台的完整代碼（如 SC-NCU-001, SC-NCU-002）
- **推薦項目數**：此推薦包含的菜單項目或補貨項目數量
- **信心分數**：AI 模型的預測信心度（百分比）
- **創建時間**：推薦生成的時間戳

### 4. 互動功能

#### 單個推薦操作：
- **👁️ 標記已讀**：將此推薦標記為已讀，從未讀列表中移除
- **🔗 前往審核/實施**：自動跳轉到「AI智能推薦」頁面進行詳細操作

#### 批量操作：
- **✅ 全部標記為已讀**：一鍵將所有未讀推薦標記為已讀

### 5. 自動刷新機制

- **刷新間隔**：每 60 秒自動檢查新推薦
- **倒計時顯示**：側邊欄底部顯示下次自動檢查的剩餘時間
- **手動刷新**：點擊 🔄 按鈕立即刷新推薦列表

### 6. 已讀狀態管理

- **會話級別**：已讀狀態僅在當前登入會話有效
- **自動標記**：查看推薦詳情或進行操作後自動標記為已讀
- **狀態重置**：登出或關閉瀏覽器後，已讀狀態會被清除

## 使用流程

### 管理員使用流程

1. **接收通知**
   - 登入系統後，如有新的 AI 推薦，側邊欄頂部會顯示紅色徽章
   - 徽章上的數字表示未讀推薦的總數

2. **查看詳情**
   - 點擊「📋 查看詳細內容」展開通知列表
   - 瀏覽各個推薦的摘要資訊

3. **處理推薦**
   - **選項 A**：點擊「標記已讀」，稍後再處理
   - **選項 B**：點擊「前往審核」或「前往實施」，立即處理推薦

4. **審核操作**
   - 系統會自動跳轉到「AI智能推薦」頁面
   - 在該頁面可以看到推薦的完整詳情
   - 進行「通過」、「拒絕」或「實施」操作

### 一般使用者使用流程

1. **接收通知**
   - 同樣可以看到 AI 推薦通知
   - 了解系統中有哪些待處理的 AI 推薦

2. **查看資訊**
   - 可以查看推薦的基本資訊
   - 了解 AI 團隊的建議內容

3. **限制**
   - 無法審核或實施推薦（需要管理員權限）
   - 可以標記為已讀，避免重複查看

## 技術實現

### 核心組件

- **模組文件**：`ai_notification.py`
- **主要函數**：
  - `render_ai_notification_widget()`：渲染通知組件
  - `render_notification_auto_refresh()`：處理自動刷新
  - `mark_as_read()`：標記已讀
  - `get_pending_and_approved_recommendations()`：獲取推薦數據

### 狀態管理

使用 `st.session_state` 儲存：
- `ai_notification_read_items`：已讀推薦ID集合
- `ai_notification_last_check`：上次檢查時間
- `ai_notification_data`：快取的推薦數據

### API 整合

- 調用 `get_ai_recommendations(status_filter="PENDING")` 獲取待審核推薦
- 調用 `get_ai_recommendations(status_filter="APPROVED")` 獲取已通過推薦
- 調用 `get_machines()` 獲取機台代碼映射

## 性能考量

- 推薦數據會快取在 session state 中
- 只在需要時才調用 API
- 自動刷新間隔設定為 60 秒，避免頻繁請求
- 已讀狀態使用 set 數據結構，查詢效率高

## 故障排除

### 問題：通知不顯示

**可能原因**：
- API 連接失敗
- 沒有待審核或已通過的推薦
- session state 未正確初始化

**解決方法**：
1. 檢查側邊欄底部的 API 連接狀態
2. 前往「AI智能推薦」頁面確認是否有推薦
3. 刷新頁面或重新登入

### 問題：機台代碼顯示為「機台-1」而不是完整代碼

**可能原因**：
- 機台資料中未設定 `machine_code` 欄位
- API 返回數據格式不正確

**解決方法**：
1. 檢查機台管理頁面，確認機台代碼已正確設定
2. 聯繫系統管理員更新機台資料

### 問題：自動刷新不工作

**可能原因**：
- 瀏覽器限制了自動重載
- session state 時間戳未更新

**解決方法**：
1. 使用手動刷新按鈕 (🔄)
2. 重新載入頁面
3. 清除瀏覽器快取
