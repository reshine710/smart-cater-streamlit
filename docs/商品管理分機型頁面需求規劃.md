# 商品管理分機型頁面需求規劃

## 📋 需求概述

將現有的商品管理頁面改造成按機型分類的頁面系統，根據商品編號（product_code）的第一個字母自動分類到對應的機型頁面。

## 🎯 功能需求

### 1. 分頁邏輯
- **A機型頁面**：顯示 `product_code` 以 "A" 開頭的所有商品
- **B機型頁面**：顯示 `product_code` 以 "B" 開頭的所有商品
- **C機型頁面**：顯示 `product_code` 以 "C" 開頭的所有商品
- **其他頁面**：顯示無法明確分類的商品（包括：
  - `product_code` 為空或 None
  - `product_code` 第一個字符不是字母
  - `product_code` 第一個字符不是 A-Z 範圍內的字母）

### 2. 分類規則詳述

#### 2.1 分類依據
- 使用欄位：`product_code`（商品代碼/產品編號）
- 分類標準：取 `product_code` 的第一個字符（轉換為大寫）
- 字母範圍：A-Z（僅限英文字母）

#### 2.2 分類邏輯
```
IF product_code 為空或 None:
    → 歸類到「其他」

IF product_code 的第一個字符不是字母:
    → 歸類到「其他」

ELSE:
    取第一個字符轉為大寫（例如 "a001" → "A"）
    IF 第一個字符在 A-Z 範圍內:
        → 歸類到對應的機型頁面（如 "A" → A機型頁面）
    ELSE:
        → 歸類到「其他」
```

#### 2.3 範例
| product_code | 第一個字符 | 分類結果 |
|-------------|----------|---------|
| "A001"      | A        | A機型頁面 |
| "a002"      | A        | A機型頁面（不區分大小寫） |
| "B123"      | B        | B機型頁面 |
| "C-456"     | C        | C機型頁面 |
| "001"       | 0        | 其他頁面（數字開頭） |
| ""          | -        | 其他頁面（空值） |
| None        | -        | 其他頁面（None） |
| "!ABC"      | !        | 其他頁面（特殊字符） |

### 3. UI/UX 設計建議

#### 3.1 機型選擇器
- **方案A：使用 Streamlit Tabs**
  - 優點：視覺清晰，符合 Streamlit 原生設計
  - 缺點：機型數量多時，tabs 會變得很長
  
- **方案B：使用 Selectbox + 動態顯示**
  - 優點：節省空間，支援任意數量機型
  - 缺點：需要手動切換，不如 tabs 直觀
  
- **方案C：混合方案**
  - 主要機型（A-Z）使用 tabs
  - 「其他」用一個按鈕或單獨的 tab

#### 3.2 推薦方案：方案B（Selectbox）

## 🔍 範例程式碼結構（僅供參考）

```python
def get_machine_type_from_product_code(product_code: Optional[str]) -> str:
    """從 product_code 提取機型代號"""
    if not product_code or not isinstance(product_code, str):
        return '其他'
    
    product_code = product_code.strip()
    if not product_code:
        return '其他'
    
    first_char = product_code[0].upper()
    if first_char.isalpha() and 'A' <= first_char <= 'Z':
        return first_char
    
    return '其他'

def categorize_menu_items_by_machine_type(menu_items: List[Dict]) -> Dict[str, List[Dict]]:
    """將菜單項目按機型分類"""
    categorized = {}
    
    for item in menu_items:
        product_code = item.get('product_code')
        machine_type = get_machine_type_from_product_code(product_code)
        
        if machine_type not in categorized:
            categorized[machine_type] = []
        
        categorized[machine_type].append(item)
    
    return categorized

def menu_management_page():
    """菜單管理頁面（按機型分類）"""
    # 1. 獲取所有菜單項目
    menu_items = st.session_state.api.get_menu_items()
    
    # 2. 按機型分類
    categorized = categorize_menu_items_by_machine_type(menu_items)
    
    # 3. 獲取可用機型列表並排序
    available_types = sorted([k for k in categorized.keys() if k != '其他'])
    if '其他' in categorized:
        available_types.append('其他')
    
    # 4. 機型選擇器
    if not available_types:
        st.info("📝 目前沒有菜單項目")
        return
    
    selected_type = st.selectbox(
        "選擇機型",
        available_types,
        format_func=lambda x: f"{x}機型" if x != '其他' else "其他",
        key="machine_type_selector"
    )
    
    # 5. 顯示選中機型的商品
    st.title(f"🍽️ 菜單管理 - {selected_type}機型")
    # ... 後續顯示邏輯
```
