## 🔄 環境切換指南

### **切換回離線測試環境**

如需切換回離線測試環境，請執行以下操作：

#### 1. **修改 `settings.toml`**
```toml
[default]
API_URL = "http://127.0.0.1:8000/api/v1"
API_URL_ONLINE = "https://scb-api-954587932054.asia-east1.run.app/api/v1"
```

#### 2. **修改 `main.py`**
```python
# 註解線上測試帳號
```

## ⚠️ 注意事項

1. **API端點確認**
   - 確保切換後的API端點可正常訪問
   - 測試連接狀態和API版本

2. **測試帳號驗證**
   - 確認測試帳號在目標環境中有效
   - 驗證權限設定正確

3. **數據一致性**
   - 注意離線和線上環境的數據可能不同步
   - 避免在不同環境間混用數據

4. **配置文件備份**
   - 切換前建議備份當前配置
   - 保留完整的環境配置記錄

5. **Git版本控制**
   - 環境切換後記得提交變更
   - 使用有意義的commit message

## 🚀 快速切換指令

### **使用Git切換**

```bash
# 查看當前變更
git diff

# 切換到線上環境（當前配置）
git checkout feat-v0.2.2

# 切換回離線環境（如有需要）
git stash  # 暫存當前變更
# 然後修改配置文件

# 恢復線上環境配置
git stash pop
```
