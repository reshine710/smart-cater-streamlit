# 機台錯誤狀態顯示邏輯說明

## 當後台機台狀態設為錯誤碼時的前台呈現

### 狀態映射規則

當 API 返回以下狀態時，前台會統一顯示為「故障」：

1. **`error`** - 直接保持為 `error`，顯示為「🔴 故障」
2. **`maintenance`** - 映射為 `error`，顯示為「🔴 故障」
3. **`missing`** - 映射為 `error`，顯示為「🔴 故障」

### 顯示效果

#### 1. 狀態總覽區塊
- **統計數字**：會計入「🔴 故障」的數量
- **顯示位置**：第三個統計卡片（col3）

#### 2. 機台總覽卡片
- **分組標題**：`### 🔴 故障 (X台)`
- **卡片樣式**：
  - 背景色：`#f8d7da`（淺紅色）
  - 邊框色：`#dc3545`（紅色）
  - 圖示：🔴
  - 標題文字：紅色

#### 3. 機台卡片詳細資訊
- **狀態顯示**：`🔴 故障`
- **操作按鈕**：
  - 如果當前狀態為 `error`：顯示「✅ 恢復上線」按鈕
  - 點擊後會調用 API 將狀態改為 `online`

#### 4. 機台詳細狀態區塊
- **狀態顯示**：`🔴 故障`
- **操作按鈕**：
  - 如果當前狀態為 `error`：顯示「✅ 恢復上線 {machine_id}」按鈕
  - 點擊後會調用 API 將狀態改為 `online`

### 程式碼流程

#### 狀態分組邏輯（`show_machine_overview`）
```python
# 第 70-83 行
for machine in valid_machines:
    status = machine.get('status', 'offline').lower()
    # 處理舊狀態的映射
    if status == 'maintenance' or status == 'missing':
        status = 'error'  # 失去心跳歸為故障
    elif status == 'unknown':
        status = 'offline'
    
    if status in status_groups:  # 'error' 在 status_groups 中
        status_groups[status].append(machine)
    else:
        status_groups['offline'].append(machine)
```

#### 狀態配置（`get_status_config`）
```python
# 第 103-137 行
def get_status_config(status: str) -> Dict:
    if status == 'maintenance' or status == 'missing':
        status = 'error'
    elif status == 'unknown':
        status = 'offline'
    
    configs = {
        'error': {
            'icon': '🔴',
            'title': '故障',
            'color': 'error',
            'bg_color': '#f8d7da',
            'border_color': '#dc3545'
        },
        # ... 其他狀態
    }
    return configs.get(status, configs['offline'])
```

#### 狀態統計（`machine_status_page`）
```python
# 第 446-465 行
for machine in valid_machines:
    status = machine.get('status', 'offline').lower()
    if status == 'maintenance' or status == 'missing':

    # 'error' 在 status_counts 中，會被正確計入
    status_counts[status] = status_counts.get(status, 0) + 1
```

### 測試案例

#### 案例 1：API 返回 `status: "error"`
- ✅ 狀態分組：進入 `error` 組
- ✅ 狀態統計：計入「🔴 故障」
- ✅ 卡片顯示：紅色背景，🔴 故障
- ✅ 操作按鈕：顯示「✅ 恢復上線」

#### 案例 2：API 返回 `status: "maintenance"`
- ✅ 狀態映射：`maintenance` → `error`
- ✅ 狀態分組：進入 `error` 組
- ✅ 狀態統計：計入「🔴 故障」
- ✅ 卡片顯示：紅色背景，🔴 故障
- ✅ 操作按鈕：顯示「✅ 恢復上線」

#### 案例 3：API 返回 `status: "missing"`
- ✅ 狀態映射：`missing` → `error`
- ✅ 狀態分組：進入 `error` 組
- ✅ 狀態統計：計入「🔴 故障」
- ✅ 卡片顯示：紅色背景，🔴 故障
- ✅ 操作按鈕：顯示「✅ 恢復上線」

### 注意事項

1. **狀態一致性**：所有錯誤相關狀態（`error`, `maintenance`, `missing`）都會統一顯示為「故障」
2. **API 映射**：前台發送狀態更新時，`error` 會映射為 `maintenance` 發送給 API
3. **預設行為**：如果狀態不在預期範圍內，會歸類為「離線」
