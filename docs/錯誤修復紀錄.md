# 🔧 錯誤修復紀錄

## 日期：2025-10-03

### 問題概述
在 Dashboard 和 Sales Analytics 頁面發現兩個主要錯誤：

1. **錯誤 1**: `'Figure' object has no attribute 'update_yaxis'`
2. **警告 2**: Plotly 棄用參數警告 - `width` 參數將被移除

---

## 錯誤 1: Figure 物件方法錯誤

### 問題描述
```
'Figure' object has no attribute 'update_yaxis'
```

**影響範圍**: `modules/dashboard.py`

### 錯誤原因
使用了不存在的 `update_yaxis()` 和 `update_xaxis()` 方法。

### 解決方案
將分散的軸標題更新合併到 `update_layout()` 中：

**修復前**:
```python
fig.update_yaxis(title='營收 (NT$)')
fig.update_xaxis(title='日期')
fig.update_layout(
    xaxis=dict(
        tickformat='%Y-%m-%d',
        tickmode='auto',
        range=[start_date, end_date]
    )
)
```

**修復後**:
```python
fig.update_layout(
    xaxis_title='日期',
    yaxis_title='營收 (NT$)',
    xaxis=dict(
        tickformat='%Y-%m-%d',
        tickmode='auto',
        range=[start_date, end_date]
    )
)
```

### 修復位置
- `modules/dashboard.py` 第 155-165 行

## 警告 2: Plotly 棄用參數

## 相關知識點

### Plotly Figure 更新方法

#### ❌ 錯誤用法
```python
fig.update_yaxis(title='Y軸標題')
fig.update_xaxis(title='X軸標題')
```

#### ✅ 正確用法
```python
fig.update_layout(
    xaxis_title='X軸標題',
    yaxis_title='Y軸標題'
)
```

或使用更詳細的配置：
```python
fig.update_layout(
    xaxis=dict(title='X軸標題', ...),
    yaxis=dict(title='Y軸標題', ...)
)
```

### Streamlit Plotly Chart 參數

#### ❌ 已棄用
```python
st.plotly_chart(fig, width="stretch")
```

#### ✅ 推薦用法
```python
st.plotly_chart(fig, width="stretch")
```

### Streamlit Dataframe 參數

#### ❌ 已棄用
```python
st.dataframe(df, width="stretch")
```

#### ✅ 推薦用法
```python
st.dataframe(df, width="stretch")
```
