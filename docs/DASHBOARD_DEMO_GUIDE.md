# 📊 Dashboard 儀表板模擬數據使用指南

## 功能說明

Dashboard 儀表板現在支援**14天模擬數據**功能，與銷售分析頁面使用相同的數據源，讓您可以在儀表板上查看完整的營運統計。

## 如何使用

### 1. 進入 Dashboard 頁面
在 Streamlit 應用中選擇「📊 營運儀表板」頁面

### 2. 啟用模擬數據
在頁面頂部勾選「**使用模擬數據**」選項

### 3. 選擇日期範圍
- 預設顯示過去 14 天（從今天往前推算）
- 您可以自訂日期範圍來查看不同時段的數據

## Dashboard 顯示內容

### 📊 統計卡片（頂部）

#### 1. 線上機台
- 顯示目前在線的販賣機數量
- 格式：`線上數/總數`
- 例如：`4/4`

#### 2. 期間營收
- 根據選擇的日期範圍顯示總營收
- 標籤自動調整：
  - 1天：「當日營收」
  - 2-7天：「N日營收」
  - 8天以上：「期間營收 (N日)」
- 格式：`NT$ XX,XXX`

#### 3. 期間交易
- 顯示選擇日期範圍內的總交易筆數
- 標籤自動調整（同營收）
- 格式：純數字

#### 4. 平均溫度
- 顯示所有訂單的平均環境溫度
- 格式：`XX.X°C`

### 📈 視覺化圖表

#### 左側：銷售趨勢圖
- **圖表類型**：折線圖
- **X軸**：日期
- **Y軸**：每日營收（NT$）
- **功能**：
  - 顯示每日營收變化趨勢
  - 自動調整日期範圍
  - 可清楚看出工作日vs週末的銷售差異
  - 顯示天氣影響下的營收波動

#### 右側：商品銷量圓餅圖
- **圖表類型**：圓餅圖
- **內容**：各商品的銷量分布
- **功能**：
  - 一目了然查看最受歡迎的商品
  - 顯示商品銷量占比
  - 幫助了解商品組合是否均衡

## 模擬數據特色

### 🍱 台灣傳統料理菜單（9種）

與銷售分析頁面完全相同：
- **主餐**（7種）：滷味三寶飯、肉粽套餐、花枝丸套餐、花枝米粉套餐、虱目魚香腸套餐、蝦捲麵套餐、雙主食青菜套餐
- **輕食**（2種）：肉粽輕食套餐、香腸肉燥飯套餐

### 📊 預期數據（14天）

- **總訂單數**：約 350-450 筆
- **總營收**：NT$ 60,000 - 75,000
- **總交易記錄**：約 550-700 筆（包含每個訂單中的各個商品）
- **平均溫度**：約 20-22°C

### 🎯 數據真實性

1. **時間模式**
   - 工作日銷量高於週末
   - 午餐和晚餐時段為高峰期
   
2. **天氣影響**
   - 晴天：基準銷量
   - 陰天：略微下降
   - 雨天：室內消費增加

3. **商品分布**
   - 輕食套餐在早餐和下午茶時段熱銷
   - 主餐套餐在午餐和晚餐時段熱銷

## 與銷售分析的差異

| 功能 | Dashboard 儀表板 | 銷售分析頁面 |
|-----|----------------|------------|
| **定位** | 快速概覽 | 深度分析 |
| **統計卡片** | ✅ 4個關鍵指標 | ✅ 4個銷售指標 |
| **趨勢圖** | ✅ 每日營收折線圖 | ✅ 每日營收 + 每小時分布 |
| **商品分析** | ✅ 圓餅圖（總覽） | ✅ 柱狀圖 + 圓餅圖（TOP10） |
| **機台比較** | ❌ | ✅ 完整機台統計 |
| **詳細資料** | ❌ | ✅ 可篩選的訂單明細 |
| **數據源** | 相同的模擬數據 | 相同的模擬數據 |

## 使用場景

### 1. 快速檢視
- 早上查看昨日或最近幾天的營運狀況
- 快速了解整體營收趨勢

### 2. 高層報告
- 向管理層展示關鍵指標
- 簡潔明瞭的視覺化呈現

### 3. 日常監控
- 監控機台在線狀態
- 觀察銷售趨勢是否正常

### 4. 功能展示
- 向客戶展示系統儀表板功能
- 無需等待真實數據累積

## 數據格式說明

Dashboard 使用的銷售數據格式包含以下欄位：

```python
{
    'timestamp': '訂單時間',
    'created_at': '創建時間',
    'order_id': '訂單編號',
    'machine_id': '機台ID',
    'item_name': '商品名稱',
    'product_name': '商品名稱（別名）',
    'quantity': 數量,
    'price': 單價,
    'amount': 小計,
    'total_amount': 總金額,
    'status': '訂單狀態',
    'payment_method': '付款方式',
    'weather': '天氣',
    'temperature': 溫度
}
```

## 切換真實數據

取消勾選「使用模擬數據」即可切換回真實 API 數據。

系統會依序嘗試：
1. `get_sales_data()` - 標準銷售數據 API
2. `get_transactional_data()` - 交易數據 API（備用）
3. 如果都沒有數據，顯示提示訊息

## 提示訊息

當沒有真實數據時，Dashboard 會顯示：
- 📊 目前沒有銷售資料，或相關 API 端點尚未配置
- 💡 提示：您可以勾選「使用模擬數據」查看功能展示

## 注意事項

⚠️ **模擬數據說明**
- 每次生成的數據略有不同（隨機性）
- 數據僅供展示，不代表真實業務
- 建議使用固定的14天範圍以獲得最佳展示效果
- Dashboard 和 Sales Analytics 使用相同的數據生成邏輯，確保數據一致性

## 技術細節

### 數據生成流程
1. `generate_demo_sales_data()` - 生成訂單數據
2. `convert_orders_to_sales_data()` - 轉換為 Dashboard 格式
3. Dashboard 自動處理並顯示統計和圖表

### 與 Sales Analytics 的整合
- 兩個頁面共享相同的菜單配置
- 使用相同的時段權重和天氣影響邏輯
- 確保數據的一致性和可比性
