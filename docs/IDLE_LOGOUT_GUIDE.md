# 🔒 閒置登出功能使用指南

## 📋 功能概述

本系統已實現30分鐘閒置登出功能，提供以下安全保護：

- ⏰ **閒置超時**：30分鐘無活動自動登出
- ⚠️ **警告提示**：25分鐘後顯示警告訊息
- 🔄 **活動重置**：任何使用者活動都會重置計時器
- 🛡️ **安全保護**：防止未授權存取

---

## 🎯 功能特點

### 1. 自動閒置檢測
- 監控滑鼠移動、點擊、鍵盤輸入等活動
- 自動計算閒置時間
- 即時更新剩餘時間顯示

### 2. 分階段警告系統
- **25分鐘**：顯示警告訊息，提醒使用者即將登出
- **30分鐘**：自動執行登出，清除所有會話資料

### 3. 使用者友善設計
- 側邊欄顯示剩餘時間
- 手動延長會話按鈕
- 清楚的狀態指示器

### 狀態管理
- `last_activity_time` - 最後活動時間戳

## 🔧 配置選項

### 時間設定
```python
# 閒置超時時間（30分鐘）
IDLE_TIMEOUT_MINUTES = 30
IDLE_TIMEOUT_SECONDS = IDLE_TIMEOUT_MINUTES * 60

# 警告時間（5分鐘前警告）
WARNING_TIME_MINUTES = 5
WARNING_TIME_SECONDS = WARNING_TIME_MINUTES * 60
```

### 自定義設定
如需修改閒置時間，請編輯 `idle_logout.py` 中的常數：
- `IDLE_TIMEOUT_MINUTES` - 總閒置時間
- `WARNING_TIME_MINUTES` - 警告提前時間

## 📊 狀態指示器

### 顏色編碼
- 🟢 **綠色**：剩餘時間 > 10分鐘（安全）
- 🟡 **黃色**：剩餘時間 5-10分鐘（注意）
- 🔴 **紅色**：剩餘時間 < 5分鐘（危險）

### 時間顯示格式
- 分鐘:秒數格式（如：25分30秒）
- 即時更新，精確到秒
- 最後活動時間顯示

## 🛠️ 故障排除

### 常見問題

**Q: 為什麼沒有顯示閒置狀態？**
A: 確保已登入系統，閒置狀態只對已登入使用者顯示。

**Q: 如何手動延長會話？**
A: 點擊側邊欄的「🔄 延長會話」按鈕，或進行任何頁面操作。

**Q: 警告訊息沒有顯示？**
A: 檢查瀏覽器控制台是否有JavaScript錯誤，確保JavaScript已正確載入。

**Q: 自動登出後如何重新登入？**
A: 系統會自動跳轉到登入頁面，使用原來的帳號密碼重新登入即可。

### 日誌檢查
系統會記錄以下事件：
- 使用者登入/登出
- 閒置警告觸發
- 自動登出執行
- 會話狀態變更

查看日誌文件：`logs/app_YYYY-MM-DD.log`
