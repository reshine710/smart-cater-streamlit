## 🔧 分類邏輯實作細節

### 產品編號格式假設
根據現有代碼（`modules/menu_management.py:67, 147`），`product_code` 的格式示例：
- `"A001"` - 標準格式
- `"B123"` - 標準格式
- `None` 或 `""` - 空值
- 可能還有其他格式

### 分類規則實作要點
```python
def get_machine_type_from_product_code(product_code: Optional[str]) -> str:
    # 1. 處理空值
    if not product_code:
        return '其他'
    
    # 2. 轉換為字串並去除空白
    product_code = str(product_code).strip()
    if not product_code:
        return '其他'
    
    # 3. 取得第一個字符並轉大寫
    first_char = product_code[0].upper()
    
    # 4. 檢查是否為 A-Z 的字母
    if first_char.isalpha() and 'A' <= first_char <= 'Z':
        return first_char
    
    # 5. 其他情況歸類為「其他」
    return '其他'
```

## ⚠️ 注意事項

### 1. Session State 管理
機型選擇應該保存到 session state，避免切換 tabs 時重置：
```python
if 'selected_machine_type' not in st.session_state:
    st.session_state.selected_machine_type = 'A'  # 預設值

selected_type = st.selectbox(
    "選擇機型",
    available_types,
    index=available_types.index(st.session_state.selected_machine_type) if st.session_state.selected_machine_type in available_types else 0,
    key="machine_type_selector",
    on_change=lambda: setattr(st.session_state, 'selected_machine_type', st.session_state.machine_type_selector)
)
```

### 2. 性能優化
- 分類邏輯只在獲取 menu_items 後執行一次
