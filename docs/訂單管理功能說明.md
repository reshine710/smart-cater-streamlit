# 訂單管理功能快速指南

## 🎯 功能概述

訂單管理模組提供完整的訂單管理解決方案，包含：

1. **📤 訂單上傳** - 批量上傳 Excel 訂單數據
2. **🔍 訂單查詢** - 多種方式查詢訂單資訊

## 🚀 快速開始

### 訪問方式

1. 使用**管理員帳號**登入系統
2. 點擊側邊欄的 **📦 訂單管理**
3. 選擇對應的功能標籤頁

## 📤 訂單上傳

### 功能特點

- ✅ 支援批量上傳多個 Excel 文件
- ✅ 上傳前數據預覽
- ✅ 預覽模式（僅檢查格式）
- ✅ 實時進度顯示
- ✅ 詳細錯誤提示

### Excel 格式要求

#### 必要欄位

| 欄位 | 說明 | 範例 |
|------|------|------|
| `order_number` | 訂單編號 | ORD-2025-001 |
| `machine_code` | 機台編號 | VM001 |
| `product_code` | 產品編號 | A001 |
| `purchase_timestamp` | 購買時間 | 2025-10-24 13:12:38 |

#### 可選欄位

- `unit_price` - 單價
- `quantity` - 數量
- `weather` - 天氣
- `temperature` - 溫度
- `humidity` - 濕度
- `payment_method` - 付款方式
- `recommended_item` - 推薦項目

### 使用步驟

1. 準備符合格式的 Excel 文件
2. 點擊「選擇 Excel 文件」
3. （可選）勾選「預覽模式」檢查格式
4. 點擊「開始上傳」
5. 查看上傳結果統計

## 🔍 訂單查詢

### 查詢方式

| 方式 | 說明 | 適用場景 |
|------|------|----------|
| 📋 **列表查詢** | 批量查詢，支援分頁和篩選 | 瀏覽大量訂單 |
| 🆔 **訂單ID查詢** | 根據數據庫ID查詢 | 精確查找特定訂單 |
| 📝 **訂單編號查詢** | 根據訂單編號查詢 | 用戶報修、追蹤訂單 |
| 🏪 **機台查詢** | 查詢特定機台的所有訂單 | 機台維護、分析 |
| 📅 **日期查詢** | 按日期範圍查詢 | 統計報表、數據分析 |

### 列表查詢參數

- **跳過筆數**：用於分頁（skip）
- **查詢筆數**：每頁顯示數量（1-500）
- **機台ID篩選**：特定機台（可選）
- **狀態篩選**：訂單狀態（可選）
  - CREATED - 已創建
  - PENDING - 處理中
  - COMPLETED - 已完成
  - CANCELLED - 已取消
  - FAILED - 失敗

### 訂單詳情

每筆訂單顯示：

- **基本資訊**：訂單編號、機台、產品、狀態
- **金額資訊**：數量、單價、總金額
- **環境資訊**：天氣、溫度、濕度
- **附加資訊**：推薦項目、訂單項目明細

## 💡 使用技巧

### 訂單上傳技巧

1. **先用預覽模式測試**：確保格式正確
2. **分批上傳**：大量數據建議分批處理
3. **保留備份**：上傳前備份原始文件
4. **檢查日誌**：遇到問題查看錯誤日誌

### 訂單查詢技巧

1. **使用適當的查詢方式**：
   - 知道訂單編號 → 使用編號查詢
   - 查看某機台訂單 → 使用機台查詢
   - 統計分析 → 使用日期查詢

2. **善用篩選功能**：
   - 組合機台和狀態篩選
   - 設定合適的日期範圍

3. **注意分頁設定**：
   - 大量數據適當增加每頁筆數
   - 使用跳過筆數進行翻頁

## 🔧 API 端點

訂單查詢使用以下 API：

```
GET /api/v1/orders                      # 列表查詢
GET /api/v1/orders/{order_id}           # ID查詢
GET /api/v1/orders/number/{order_number} # 編號查詢
GET /api/v1/orders/machine/{machine_id}  # 機台查詢
GET /api/v1/ai/transactional-data       # 日期查詢（AI API）
```

## 🚨 常見問題

### 上傳問題

**Q: 上傳失敗，提示「找不到機台」**
- A: 確認 Excel 中的機台編號在資料庫中存在

**Q: 時間格式錯誤**
- A: 使用支援的時間格式（參見完整文檔）

**Q: 部分訂單上傳失敗**
- A: 查看錯誤訊息，修正問題後重新上傳失敗的訂單

### 查詢問題

**Q: 查詢結果為空**
- A: 檢查篩選條件是否正確，嘗試放寬查詢條件

**Q: 日期查詢無結果**
- A: 確認日期範圍內有訂單數據

**Q: 機台查詢失敗**
- A: 確認機台ID正確，該機台有訂單記錄
