# 訂單管理功能快速指南

## 🎯 功能概述

訂單管理模組提供完整的訂單管理解決方案，包含：

1. **📤 訂單上傳** - 批量上傳 Excel 訂單數據
2. **🔍 訂單查詢** - 多種方式查詢訂單資訊
3. **🗑️ 訂單刪除** - 按日期或訂單編號刪除訂單

## 🚀 快速開始

### 訪問方式

1. 使用**管理員帳號**登入系統
2. 點擊側邊欄的 **🧮 訂單管理**
3. 選擇對應的功能標籤頁：
   - **📤 訂單上傳** - 上傳 Excel 文件
   - **🔍 訂單查詢** - 查詢訂單資料
   - **🗑️ 訂單刪除** - 刪除訂單（需謹慎）

## 📤 訂單上傳

### 功能特點

- ✅ 支援批量上傳多個 Excel 文件
- ✅ 上傳前數據預覽
- ✅ 預覽模式（僅檢查格式）
- ✅ 實時進度顯示
- ✅ 詳細錯誤提示

### Excel 格式要求

#### 必要欄位

| 欄位 | 說明 | 範例 |
|------|------|------|
| `order_number` | 訂單編號 | ORD-2025-001 |
| `machine_code` | 機台編號 | VM001 |
| `product_code` | 產品編號 | A001 |
| `purchase_timestamp` | 購買時間 | 2025-10-24 13:12:38 |

#### 可選欄位

- `unit_price` - 單價
- `quantity` - 數量
- `weather` - 天氣
- `temperature` - 溫度
- `humidity` - 濕度
- `payment_method` - 付款方式
- `recommended_item` - 推薦項目

### 使用步驟

1. 準備符合格式的 Excel 文件
2. 點擊「選擇 Excel 文件」
3. （可選）勾選「預覽模式」檢查格式
4. 點擊「開始上傳」
5. 查看上傳結果統計

## 🗑️ 訂單刪除

### ⚠️ 重要警告

**訂單刪除操作無法撤銷！請務必謹慎使用。**

- 建議在刪除前先備份數據
- 確認無誤後再執行刪除
- 所有刪除操作都需要安全確認

### 刪除方式

#### 1. 📅 按日期範圍刪除

批量刪除指定日期範圍內的所有訂單：

**使用步驟**：
1. 選擇開始日期和結束日期
2. 系統顯示將要刪除的日期範圍
3. 輸入 `DELETE` 進行安全確認
4. 點擊「確認刪除」執行操作
5. 查看刪除結果統計

**特點**：
- 支援單日或多日刪除
- 自動驗證日期合理性
- 顯示刪除前後統計資訊
- 包含安全確認機制

#### 2. 📝 按訂單編號刪除

精確刪除單筆訂單：

**使用步驟**：
1. 輸入訂單編號
2. 再次輸入訂單編號進行確認
3. 點擊「確認刪除」執行操作
4. 查看刪除結果

**特點**：
- 精確刪除指定訂單
- 雙重確認防止誤刪
- 自動關聯刪除訂單項目

### 刪除統計資訊

刪除完成後顯示：
- **刪除前數量**：找到的訂單總數
- **成功刪除**：成功刪除的訂單數
- **剩餘**：刪除失敗或跳過的訂單數

## 🔍 訂單查詢

### 查詢方式

| 方式 | 說明 | 適用場景 |
|------|------|----------|
| 📋 **列表查詢** | 批量查詢，支援分頁和篩選 | 瀏覽大量訂單 |
| 📝 **訂單編號查詢** | 根據訂單編號查詢 | 用戶報修、追蹤訂單 |
| 🏪 **機台查詢** | 下拉選單選擇機台，可設定查詢筆數 | 機台維護、分析 |

### 查詢參數

#### 列表查詢
- **頁數**：從 1 開始的頁碼（原 skip 參數已改為 page）
- **查詢筆數**：每頁顯示數量（1-500）
- **機台ID篩選**：特定機台（可選）
- **狀態篩選**：訂單狀態（可選）
  - CREATED - 已創建
  - PENDING - 處理中
  - COMPLETED - 已完成
  - CANCELLED - 已取消
  - FAILED - 失敗

#### 機台查詢
- **機台選擇**：下拉選單選擇機台
- **查詢筆數**：設定查詢數量上限（1-1000筆，預設100筆）
  - 透過 `page` / `limit` 參數向 API 請求
  - 系統同時回傳 `total`（總筆數）與 `items`（當前頁資料）
  - 建議值：
    - 快速查看最近訂單：50-100筆
    - 詳細分析：200-500筆
    - 完整歷史：500-1000筆

### 訂單詳情

每筆訂單顯示：

- **基本資訊**：訂單編號、機台、產品、狀態
- **金額資訊**：數量、單價、總金額
- **環境資訊**：天氣、溫度、濕度
- **附加資訊**：推薦項目、訂單項目明細

## 💡 使用技巧

### 訂單上傳技巧

1. **先用預覽模式測試**：確保格式正確
2. **分批上傳**：大量數據建議分批處理
3. **保留備份**：上傳前備份原始文件
4. **檢查日誌**：遇到問題查看錯誤日誌

### 使用技巧

#### 訂單查詢技巧

1. **使用適當的查詢方式**：
   - 知道訂單編號 → 使用編號查詢
   - 查看某機台訂單 → 使用機台查詢
   - 統計分析 → 使用日期查詢

2. **善用篩選功能**：
   - 組合機台和狀態篩選
   - 設定合適的日期範圍

3. **注意分頁設定**：
   - 大量數據適當增加每頁筆數
   - 使用跳過筆數進行翻頁

#### 訂單刪除技巧

1. **刪除前的準備**：
   - ✅ 確認要刪除的訂單範圍
   - ✅ 備份重要數據
   - ✅ 通知相關人員

2. **選擇合適的刪除方式**：
   - 測試數據、批量清理 → 按日期範圍刪除
   - 錯誤訂單、單筆修正 → 按訂單編號刪除

3. **安全確認**：
   - 仔細檢查日期範圍
   - 準確輸入確認文字
   - 查看刪除結果統計

GET /api/v1/orders/machine/{machine_id}  # 機台查詢

## 🚨 常見問題

### 刪除問題

**Q: 刪除的訂單可以恢復嗎？**
- A: 不可以。訂單刪除是永久性的，無法恢復。請務必在刪除前確認。

**Q: 刪除訂單會影響統計數據嗎？**
- A: 是的。刪除訂單後，相關的統計數據會相應改變。

**Q: 為什麼有些訂單刪除失敗？**
- A: 可能原因：
  - 訂單有關聯數據（如推薦記錄）
  - 資料庫連接問題
  - 權限不足
  - 查看錯誤日誌了解詳情

**Q: 如何批量刪除測試數據？**
- A: 使用「按日期範圍刪除」功能，選擇測試數據的日期範圍。

### 上傳問題

**Q: 上傳失敗，提示「找不到機台」**
- A: 確認 Excel 中的機台編號在資料庫中存在

**Q: 時間格式錯誤**
- A: 使用支援的時間格式（參見完整文檔）

**Q: 部分訂單上傳失敗**
- A: 查看錯誤訊息，修正問題後重新上傳失敗的訂單

### 查詢問題

**Q: 查詢結果為空**
- A: 檢查篩選條件是否正確，嘗試放寬查詢條件

**Q: 日期查詢無結果**
- A: 確認日期範圍內有訂單數據

**Q: 機台查詢失敗**
- A: 確認機台ID正確，該機台有訂單記錄
