# 訂單管理功能說明

## 📋 功能概述

訂單管理功能提供兩大核心功能：

1. **訂單上傳** - 批量上傳 Excel 格式的訂單數據到資料庫
2. **訂單查詢** - 多種方式查詢和檢視訂單資料

## 🎯 功能特點

### 訂單上傳
- **Web 界面操作**：簡單直觀的上傳界面
- **批量處理**：支持同時上傳多個 Excel 文件
- **數據預覽**：上傳前可以預覽數據內容
- **預覽模式**：可以只檢查數據格式而不實際上傳
- **詳細反饋**：實時顯示上傳進度和結果統計
- **錯誤處理**：清晰的錯誤提示和日誌記錄
- **兼容性強**：支持新舊兩種欄位格式

### 訂單查詢
- **多種查詢方式**：支持列表、ID、編號、機台、日期等查詢方式
- **分頁顯示**：大量數據分頁顯示，提升瀏覽體驗
- **詳細資訊**：完整顯示訂單詳情、環境資訊、推薦項目等
- **篩選功能**：可按機台、狀態、日期範圍篩選
- **即時查詢**：快速響應，實時顯示查詢結果

## 🚀 使用方法

### 1. 訪問功能

1. 使用管理員帳號登入系統
2. 在側邊欄選單中點擊 **🧮 訂單管理**
3. 選擇相應的標籤頁：
   - **📤 訂單上傳** - 上傳 Excel 文件
   - **🔍 訂單查詢** - 查詢訂單資料

### 2. 準備 Excel 文件

Excel 文件必須包含以下**必要欄位**：

| 欄位名稱（新） | 欄位名稱（舊） | 說明 | 範例 |
|--------------|--------------|------|------|
| `order_number` | `transaction_id` | 訂單編號 | ORD-2025-001 |
| `machine_code` | `machine_id` | 機台編號 | VM001 |
| `purchase_timestamp` | - | 購買時間 | 2025-10-24 13:12:38 |
| `product_code` | `meal_id` | 產品編號 | A001 |

**可選欄位**：

| 欄位名稱（新） | 欄位名稱（舊） | 說明 | 預設值 |
|--------------|--------------|------|--------|
| `unit_price` | - | 單價 | 產品預設價格 |
| `quantity` | `quantity_sold` | 數量 | 1 |
| `weather` | - | 天氣狀況 | UNKNOWN |
| `temperature` | `temperature_celsius` | 溫度 | 25.0 |
| `humidity` | - | 濕度 | NULL |
| `payment_method` | - | 付款方式 | cash |
| `payment_number` | `bill_number` | 金流編號 | NULL |
| `recommended_item` | `recommend`, `recommand` | 推薦項目 | NULL |

### 3. 支援的時間格式

系統支援以下時間格式：

- `YYYY-MM-DD HH:MM:SS` (例: 2025-10-24 13:12:38)
- `YYYY/MM/DD HH:MM:SS` (例: 2025/10/24 13:12:38)
- `YYYY-MM-DD HH:MM` (例: 2025-10-24 13:12)
- `YYYY/MM/DD HH:MM` (例: 2025/10/24 13:12)

### 4. 上傳步驟

1. **選擇文件**
   - 點擊「選擇 Excel 文件」按鈕
   - 可以同時選擇多個文件（支援 .xlsx 和 .xls 格式）

2. **預覽數據**（可選）
   - 勾選「🔍 預覽模式」只檢查數據格式
   - 系統會顯示：
     - 文件資訊（大小、筆數）
     - 欄位列表
     - 前 5 筆數據預覽

3. **開始上傳**
   - 點擊「🚀 開始上傳」按鈕
   - 系統會顯示：
     - 處理進度
     - 每個文件的上傳結果
     - 成功/失敗統計
     - 錯誤訊息（如有）

4. **查看結果**
   - 總體統計：處理文件數、總資料筆數、成功/失敗數量
   - 詳細錯誤訊息（如有失敗記錄）

## 🔧 技術實現

### 核心邏輯

程式碼參考了原始的命令行上傳腳本 `upload_orders_from_xlsx.py`，實現了以下核心功能：

1. **資料庫連接**：自動從環境變數讀取資料庫配置
2. **數據驗證**：檢查必要欄位和數據格式
3. **時間解析**：支援多種日期時間格式
4. **環境情境處理**：自動創建或關聯環境情境記錄
5. **訂單創建**：建立訂單主記錄和訂單項目
6. **事務管理**：確保數據一致性

### 資料庫操作

- 使用 SQLAlchemy ORM 進行資料庫操作
- 支援事務回滾，確保數據完整性
- 自動關聯機台、產品、地點等相關記錄

### 錯誤處理

- 詳細的錯誤訊息提示
- 日誌記錄所有操作和錯誤
- 失敗記錄不影響其他記錄的處理

## 📊 數據流程

```
Excel 文件上傳
    ↓
讀取並解析數據
    ↓
驗證必要欄位
    ↓
連接資料庫
    ↓
逐筆處理訂單：
  - 驗證機台和產品存在
  - 創建/關聯環境情境
  - 創建訂單記錄
  - 創建訂單項目
  - 更新推薦項目（如有）
    ↓
提交事務
    ↓
顯示結果統計
```

## 🔍 故障排除

### 常見錯誤

1. **找不到機台**
   - 錯誤：`找不到機台: VMXXX`
   - 解決：確認機台編號在資料庫中存在

2. **找不到產品**
   - 錯誤：`找不到產品: AXXX`
   - 解決：確認產品編號在菜單項目中存在

3. **時間格式錯誤**
   - 錯誤：`無法解析時間格式: ...`
   - 解決：確認時間格式符合支援的格式之一

4. **資料庫連接失敗**
   - 錯誤：`資料庫連接失敗: ...`
   - 解決：檢查環境變數配置和資料庫連接狀態

5. **缺少必要欄位**
   - 錯誤：`缺少必要欄位: ...`
   - 解決：確認 Excel 文件包含所有必要欄位

## 📋 訂單查詢功能使用說明

### 查詢方式

#### 1. 📋 列表查詢

批量查詢訂單，支援分頁和篩選：

- **跳過筆數**：設定要跳過的記錄數（用於分頁）
- **查詢筆數**：每次查詢返回的訂單數量（1-500）
- **機台ID篩選**：可選，篩選特定機台的訂單
- **狀態篩選**：可選，篩選特定狀態的訂單
  - 全部
  - CREATED - 已創建
  - PENDING - 處理中
  - COMPLETED - 已完成
  - CANCELLED - 已取消
  - FAILED - 失敗

**使用步驟**：
1. 設定查詢參數
2. 點擊「🔍 開始查詢」
3. 查看查詢結果和統計資訊
4. 展開訂單查看詳細資訊

#### 2. 🆔 訂單ID查詢

根據訂單的數據庫ID快速查詢單筆訂單：

- 輸入訂單ID（數字）
- 點擊查詢
- 立即顯示該訂單的完整資訊

#### 3. 📝 訂單編號查詢

根據訂單編號（order_number）查詢：

- 輸入訂單編號（例如：600000031762416122）
- 點擊查詢
- 顯示該訂單編號對應的訂單資訊

#### 3. 🏪 機台查詢

使用下拉選單選擇機台，查詢該機台的所有訂單：

**使用步驟**：
1. 系統自動載入所有機台列表
2. 從下拉選單選擇機台（顯示格式：機台名稱 (機台編碼) - 地點）
3. 設定查詢筆數（1-1000筆，預設100筆）
4. 系統顯示選中機台的詳細資訊
5. 點擊「查詢訂單」按鈕
6. 查看查詢結果和統計資訊

**特點**：
- 直觀的下拉選單，無需記憶機台ID
- 顯示機台名稱、編碼和地點資訊
- 可自訂查詢筆數，避免載入過多數據
- 自動統計：查詢筆數、總金額、平均金額
- 如達到查詢上限會顯示提醒
- 展開查看每筆訂單的詳細資訊

#### 5. 📅 日期查詢

按日期範圍查詢訂單（使用 AI API）：

- **開始日期**：設定查詢起始日期
- **結束日期**：設定查詢結束日期
- **機台ID篩選**：可選，篩選特定機台
- **查詢筆數上限**：設定最多返回的記錄數（1-1000）

**特點**：
- 使用日期選擇器，操作直觀
- 支援日期範圍查詢
- 可組合機台篩選
- 顯示分頁資訊

### 查詢結果顯示

#### 機台查詢統計資訊
- **查詢筆數**：實際查詢到的訂單數量
- **總金額**：所有訂單的金額總和
- **平均金額**：每筆訂單的平均金額
- **達到上限提醒**：如查詢結果達到設定的筆數上限，系統會提醒可能還有更多訂單

#### 訂單詳情顯示

每筆訂單以 JSON 格式顯示完整資訊，包含：

**基本資訊**：
- 訂單ID / 訂單編號
- 機台編碼
- 產品編碼
- 訂單狀態
- 付款狀態

**金額資訊**：
- 數量
- 單價
- 總金額
- 建立時間

**環境資訊**（如有）：
- 天氣狀況
- 溫度
- 濕度

**其他資訊**：
- 推薦項目
- 訂單項目明細
