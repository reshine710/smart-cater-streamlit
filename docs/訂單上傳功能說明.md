# 訂單上傳功能說明

## 📋 功能概述

訂單上傳功能允許管理員通過 Web 界面批量上傳 Excel 格式的訂單數據到資料庫，無需使用命令行工具。

## 🎯 功能特點

- **Web 界面操作**：簡單直觀的上傳界面
- **批量處理**：支持同時上傳多個 Excel 文件
- **數據預覽**：上傳前可以預覽數據內容
- **預覽模式**：可以只檢查數據格式而不實際上傳
- **詳細反饋**：實時顯示上傳進度和結果統計
- **錯誤處理**：清晰的錯誤提示和日誌記錄
- **兼容性強**：支持新舊兩種欄位格式

## 🚀 使用方法

### 1. 訪問功能

1. 使用管理員帳號登入系統
2. 在側邊欄選單中點擊 **📤 訂單上傳**

### 2. 準備 Excel 文件

Excel 文件必須包含以下**必要欄位**：

| 欄位名稱（新） | 欄位名稱（舊） | 說明 | 範例 |
|--------------|--------------|------|------|
| `order_number` | `transaction_id` | 訂單編號 | ORD-2025-001 |
| `machine_code` | `machine_id` | 機台編號 | VM001 |
| `purchase_timestamp` | - | 購買時間 | 2025-10-24 13:12:38 |
| `product_code` | `meal_id` | 產品編號 | A001 |

**可選欄位**：

| 欄位名稱（新） | 欄位名稱（舊） | 說明 | 預設值 |
|--------------|--------------|------|--------|
| `unit_price` | - | 單價 | 產品預設價格 |
| `quantity` | `quantity_sold` | 數量 | 1 |
| `weather` | - | 天氣狀況 | UNKNOWN |
| `temperature` | `temperature_celsius` | 溫度 | 25.0 |
| `humidity` | - | 濕度 | NULL |
| `payment_method` | - | 付款方式 | cash |
| `payment_number` | `bill_number` | 金流編號 | NULL |
| `recommended_item` | `recommend` | 推薦項目 | NULL |

### 3. 支援的時間格式

系統支援以下時間格式：

- `YYYY-MM-DD HH:MM:SS` (例: 2025-10-24 13:12:38)
- `YYYY/MM/DD HH:MM:SS` (例: 2025/10/24 13:12:38)
- `YYYY-MM-DD HH:MM` (例: 2025-10-24 13:12)
- `YYYY/MM/DD HH:MM` (例: 2025/10/24 13:12)

### 4. 上傳步驟

1. **選擇文件**
   - 點擊「選擇 Excel 文件」按鈕
   - 可以同時選擇多個文件（支援 .xlsx 和 .xls 格式）

2. **預覽數據**（可選）
   - 勾選「🔍 預覽模式」只檢查數據格式
   - 系統會顯示：
     - 文件資訊（大小、筆數）
     - 欄位列表
     - 前 5 筆數據預覽

3. **開始上傳**
   - 點擊「🚀 開始上傳」按鈕
   - 系統會顯示：
     - 處理進度
     - 每個文件的上傳結果
     - 成功/失敗統計
     - 錯誤訊息（如有）

4. **查看結果**
   - 總體統計：處理文件數、總資料筆數、成功/失敗數量
   - 詳細錯誤訊息（如有失敗記錄）

## 🔧 技術實現

### 核心邏輯

程式碼參考了原始的命令行上傳腳本 `upload_orders_from_xlsx.py`，實現了以下核心功能：

1. **資料庫連接**：自動從環境變數讀取資料庫配置
2. **數據驗證**：檢查必要欄位和數據格式
3. **時間解析**：支援多種日期時間格式
4. **環境情境處理**：自動創建或關聯環境情境記錄
5. **訂單創建**：建立訂單主記錄和訂單項目
6. **事務管理**：確保數據一致性

### 資料庫操作

- 使用 SQLAlchemy ORM 進行資料庫操作
- 支援事務回滾，確保數據完整性
- 自動關聯機台、產品、地點等相關記錄

### 錯誤處理

- 詳細的錯誤訊息提示
- 日誌記錄所有操作和錯誤
- 失敗記錄不影響其他記錄的處理

## 📊 數據流程

```
Excel 文件上傳
    ↓
讀取並解析數據
    ↓
驗證必要欄位
    ↓
連接資料庫
    ↓
逐筆處理訂單：
  - 驗證機台和產品存在
  - 創建/關聯環境情境
  - 創建訂單記錄
  - 創建訂單項目
  - 更新推薦項目（如有）
    ↓
提交事務
    ↓
顯示結果統計
```

## 🔍 故障排除

### 常見錯誤

1. **找不到機台**
   - 錯誤：`找不到機台: VMXXX`
   - 解決：確認機台編號在資料庫中存在

2. **找不到產品**
   - 錯誤：`找不到產品: AXXX`
   - 解決：確認產品編號在菜單項目中存在

3. **時間格式錯誤**
   - 錯誤：`無法解析時間格式: ...`
   - 解決：確認時間格式符合支援的格式之一

4. **資料庫連接失敗**
   - 錯誤：`資料庫連接失敗: ...`
   - 解決：檢查環境變數配置和資料庫連接狀態

5. **缺少必要欄位**
   - 錯誤：`缺少必要欄位: ...`
   - 解決：確認 Excel 文件包含所有必要欄位

## 📈 性能考量

- **批次處理**：支援一次處理多個文件
- **事務管理**：每個訂單獨立事務，失敗不影響其他訂單
- **記憶體管理**：使用 pandas 分批讀取大文件
- **日誌記錄**：所有操作都有詳細日誌可供追蹤

## 🔒 安全性

- **權限控制**：僅管理員可訪問此功能
- **數據驗證**：嚴格驗證所有輸入數據
- **事務安全**：失敗自動回滾，保證數據一致性
- **日誌審計**：記錄所有操作供後續審計

## 🎓 使用建議

1. **小批次測試**：首次使用時建議先上傳少量數據測試
2. **使用預覽模式**：上傳前先用預覽模式檢查數據格式
3. **保留備份**：上傳前備份原始 Excel 文件
4. **檢查日誌**：如遇問題，查看系統日誌了解詳情
5. **分批上傳**：大量數據建議分批上傳，便於問題定位
