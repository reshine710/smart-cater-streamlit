# 🎯 模擬數據功能總覽

## 概述

本系統已在 **Dashboard 儀表板** 和 **Sales Analytics 銷售分析** 兩個頁面實現完整的14天模擬數據功能，使用相同的台灣傳統料理菜單和數據生成邏輯。

## 📍 功能位置

### 1. 📊 Dashboard 儀表板
- **路徑**: 主選單 → 📊 營運儀表板
- **文件**: `modules/dashboard.py`
- **功能**: 快速概覽、關鍵指標展示

### 2. 📈 Sales Analytics 銷售分析
- **路徑**: 主選單 → 📈 銷售分析
- **文件**: `modules/sales_analytics.py`
- **功能**: 深度分析、詳細報表

## 🎯 使用方式

### Dashboard 頁面
```
1. 進入「📊 營運儀表板」
2. 勾選「使用模擬數據」
3. 選擇日期範圍（建議14天）
4. 查看統計卡片和趨勢圖
```

### Sales Analytics 頁面
```
1. 進入「📈 銷售分析」
2. 勾選「使用模擬數據」
3. 選擇日期範圍（建議14天）
4. 查看完整的分析報表和圖表
```

## 🔄 真實數據切換

兩個頁面都支援無縫切換：
- **啟用模擬**: 勾選「使用模擬數據」
- **切換真實**: 取消勾選

真實數據來源：
- Dashboard: `get_sales_data()` / `get_transactional_data()`
- Sales Analytics: `get_orders_data()`
